Student attendance system

Sistem absensi berbasis PHP Native yang mendukung pencatatan kehadiran melalui pengenalan wajah, kamera, dan geolocation. Project ini mencakup alur absensi pengguna, validasi lokasi, riwayat kehadiran, pengelolaan cuti, hingga laporan administrasi.

PHP NativeFace recognitionGeolocationReporting
01 / LoginHalaman autentikasi pengguna.
02 / DashboardRingkasan status absensi dan navigasi utama.
03 / Responsive viewTampilan ringkas untuk perangkat mobile.
04 / Attendance historyDetail waktu, foto, dan koordinat absensi.
05 / Location validationValidasi radius lokasi sebelum absensi diproses.
06 / Report exportOpsi ekspor laporan untuk kebutuhan administrasi.
07 / Attendance reportTabel rekapitulasi data kehadiran.
08 / Leave requestForm pengajuan cuti dan pencatatan keterangan.

Bukti visual di atas menampilkan beberapa alur utama yang dikerjakan, mulai dari login dan absensi sampai validasi lokasi, riwayat kehadiran, laporan, dan pengajuan cuti.
