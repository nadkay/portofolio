# Nadia Kayla Dhinita — Portfolio

Static portfolio website built with HTML, CSS, and JavaScript.

## Deploy to Vercel

1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Leave the framework preset as **Other**.
4. Keep the build command empty and deploy.

`vercel.json` enables clean URLs, so the deployed site uses `/` instead of showing `index.html`.
